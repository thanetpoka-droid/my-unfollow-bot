# คู่มือการใช้งาน Instagram Unfollow Manager (ครบทุกสเตป)

ชุดสคริปต์นี้แบ่งการทำงานออกเป็น 2 ขั้นตอนเพื่อความปลอดภัยสูงสุดของบัญชี

---

## สเตปที่ 1: ติดตั้งเครื่องมือ (ทำแค่ครั้งแรกครั้งเดียว)
1. แตกไฟล์ `.zip` นี้ไว้ในโฟลเดอร์ที่ต้องการ
2. ดับเบิลคลิกไฟล์ **`install_dependencies.bat`** (หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `python -m pip install playwright` ตามด้วย `python -m playwright install chromium`)
3. รอจนหน้าต่างติดตั้งขึ้นข้อความว่า `ติดตั้งเสร็จสมบูรณ์!`

---

## สเตปที่ 2: ดึงรายชื่อคนที่ไม่ได้ฟอลโลกลับ (ปลอดภัย 100%)
1. เข้าแอป Instagram -> **การตั้งค่า (Settings)** -> **ศูนย์บัญชี (Accounts Center)**
2. เลือก **ข้อมูลและการอนุญาตของคุณ** -> **ดาวน์โหลดข้อมูลของคุณ**
3. เลือกดาวน์โหลดเฉพาะ **ผู้ติดตามและกำลังติดตาม (Followers and following)** โดยตั้งค่ารูปแบบไฟล์เป็น **JSON**
4. แตกไฟล์ที่โหลดมา นำไฟล์ **`followers_1.json`** และ **`following.json`** มาวางไว้ในโฟลเดอร์เดียวกับสคริปต์นี้
5. เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
   ```bash
   python check_not_following_back.py
   ```
6. ระบบจะสร้างไฟล์ **`target_users.txt`** ขึ้นมา ให้เปิดไฟล์นี้เพื่อเช็กและลบบัญชีที่ยังอยากติดตามอยู่ออกก่อน

---

## สเตปที่ 3: รันบอทช่วยเลิกติดตาม (แนะนำทดสอบกับบัญชีสำรองก่อน)
1. เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
   ```bash
   python unfollow_bot.py
   ```
2. หน้าต่างเบราว์เซอร์ Chrome จะเด้งขึ้นมา ให้ **ล็อกอิน Instagram ด้วยตัวเอง**
3. เมื่อล็อกอินเสร็จแล้ว ให้กลับมาที่หน้าต่าง Terminal แล้วกดปุ่ม **Enter**
4. บอทจะทยอยเลิกติดตามตามรายชื่อใน `target_users.txt` โดยมีการสุ่มหน่วงเวลา 18–38 วินาทีต่อคน และจำกัดไว้ที่ 10 คนต่อรอบ (รายชื่อที่ทำเสร็จแล้วจะถูกลบออกจาก `target_users.txt` อัตโนมัติ เพื่อรันต่อในรอบถัดไปได้ทันที)
